# Genius Children Senior Secondary School Website

Static responsive school website built with HTML, CSS and JavaScript.

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Assets
- `assets/logo.png` = uploaded school logo
- `assets/hero.mp4` = uploaded hero video

## Important
The enquiry form is frontend-ready but does not send data to a server yet.
Connect the submit handler in `script.js` to your preferred backend, email service, Google Sheets, Firebase, Supabase, etc.

Replace placeholder gallery/facility/news content with official school information before publishing.
